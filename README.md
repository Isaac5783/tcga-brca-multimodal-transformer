# Multimodal Pathology Transformer

A small research-oriented project exploring multimodal learning with
Transformer architectures for computational pathology.

## Project Goal

The project will investigate how pathology image representations and
molecular data can be combined using Transformer-based models for
patient-level prediction.

## Current Stage

- Exploring publicly available TCGA data
- Identifying an appropriate cancer cohort
- Verifying matched open-access pathology and molecular data
- Designing a small multimodal Transformer
